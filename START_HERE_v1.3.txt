SCRIBIT v1.3 — RATE-LIMIT-SAFE PROCESSING
==========================================

This is a normal update on the permanent signed release line.

IF YOUR PHONE CURRENTLY HAS THE PERMANENTLY SIGNED v1.2.0:
- Keep Scribit installed.
- Push this update to the same GitHub repo.
- Download Scribit.apk from the v1.3.0 Release.
- Open it and choose Android's normal Update option.
- Your private archive, database, settings and API setup stay in place.

IF YOUR PHONE STILL HAS AN OLD PRE-v1.2 DEBUG BUILD:
- That old temporary signer still cannot update to the permanent release signer.
- Do the one-time migration to a signed v1.2+ build first.

WHAT v1.3 CHANGES:
- Multiple imports are serialized into one persistent WorkManager AI queue.
- HTTP 429 rate limits retry automatically; no Retry button is needed for normal throttling.
- Retry-After is honoured when the provider sends it.
- Temporary timeout / 408 / 425 / 5xx failures retry automatically with backoff.
- Authentication, invalid requests and known exhausted billing/quota errors still stop for human action.
- Library UI shows Queued / Processing / Retrying automatically.

The package ID and permanent signing setup are unchanged.
Do not generate a new signing key.
