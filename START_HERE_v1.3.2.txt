SCRIBIT v1.3.2 — DUPLICATE FIX
=================================

This is a normal Scribit update. Do NOT uninstall the current signed app.

1. Replace your repo files with this patch/full project.
2. Run UPDATE_GITHUB.cmd.
3. Wait for GitHub Actions to publish Scribit v1.3.2.
4. Download Scribit.apk from the v1.3.2 Release.
5. Open it on your phone and choose Update.

New in 1.3.2:
- Duplicate detection uses exact file contents only — never similar names.
- Renamed byte-for-byte copies are still detected.
- Duplicates are imported instead of blocked.
- Matching documents are marked red so you choose what to keep.
- Open a red document and tap Keep this copy to dismiss the warning.
- About Scribit now shows only Version and Build.
- Public release notes are cleaned up.

Normal update installation keeps your existing Scribit data.
